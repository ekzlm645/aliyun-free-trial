## 到期和扣费：预付费与按量付费的行为完全不同

这是整篇文章里最值得先看的一节。两种计费模式的试用，到期后的处理逻辑完全不同：

| 对比项 | 包年包月（预付费） | 按量付费（后付费） |
| --- | --- | --- |
| 到期后会怎样 | 自动关闭并释放实例 | 不会自动停，按实际用量继续从账户扣费 |
| 你需要做什么 | 到期前备份数据，决定是否续费 | 不用了及时手动释放 |
| 续费方式 | 可以随时续费，有效期自动延长 | 无需续费，保证余额充足即可，余额不足会欠费 |

包年包月的试用有自动兜底，到期就停。按量付费的试用灵活，但忘了释放就会一直计费，官方文档对这点写得直白：试用结束后会直接从账户扣费，不需要继续使用就及时手动释放。

还有几条规则容易被忽略：

- 数据保留时间有限。试用到期后数据会保留1~15天（各产品不同），期间不续费，实例释放、数据清理，要保留的东西提前备份。
- 试用额度当月有效，不结转。某个月没用完的额度，下个月清零。
- 自己买的资源包会优先被消耗。比如OSS免费给20GB，你又买了40GB资源包，系统会先扣你花钱买的那40GB，扣完才轮到免费的20GB。想先消耗免费额度，就别急着买资源包。
- 超出免费额度的部分按标准价计费。升级固定带宽、系统盘超出范围、按量付费转包年包月，这些操作都会产生费用。
- 释放后没有后悔药。手动释放的实例找不回，而且释放后无法再次参与同款产品的免费试用。
- 非预期费用可以申请退款。开通试用后如果出现账单，先去“我的试用”检查是否超过试用周期、是否用了非免费功能，确认属于非预期费用可申请退回。

## 常见问题

**试用时间可以延长吗？**
不能。每个账号对同一产品只有一次试用权益，时长无法延长。到期后有需要就购买，不需要就及时清理资源。

**为什么提示“不符合试用规则”？**
把鼠标停在置灰的领取按钮上，系统会显示具体原因。最常见的三种：没完成实名认证；这个账号（或同人账号）以前购买或试用过该产品；不是从试用中心页面进入开通的。

**试用到期后数据还在吗？**
到期后数据保留1~15天，具体看各产品规则。期间续费可以继续使用，不续费到期满后实例释放、数据清理。

**这个月没用完的试用额度能留到下个月吗？**
不能，试用额度仅限当月使用。

**开通试用后为什么产生了费用？**
三种常见原因：超过了试用周期；开通或使用了非免费功能；超出免费额度，比如升级了固定带宽、系统盘超出范围。超出部分按标准价计费。确认属于非预期费用，可以申请退款。
